# Zomatogram

A Zomato-style food reels web application built using the MERN stack. The platform allows restaurants/vendors to upload food reels and showcase their restaurant details through dedicated vendor pages.

## Features

* Upload and view food reels
* Vendor-specific restaurant pages
* Display restaurant information and media content
* Responsive user interface
* Seamless interaction between frontend and backend
* MongoDB-based data storage

## Tech Stack

* **Frontend:** React.js
* **Backend:** Node.js, Express.js
* **Database:** MongoDB

## Project Overview

Zomatogram provides an engaging way for users to discover restaurants through short-form food videos. Vendors can manage their content, while users can browse reels and explore restaurant profiles in an intuitive interface.
